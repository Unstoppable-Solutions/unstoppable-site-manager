# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Email **support@unstoppablesolutions.app** with:

- a description of the issue and its impact,
- steps to reproduce (a proof of concept if you have one),
- the Unstoppable Site Manager version you tested.

You will get a reply within two business days. Fixes are released as quickly as possible, and reporters are credited in the changelog unless they prefer not to be.

## Supported versions

Only the latest release receives security fixes. Please update before reporting.
